# T8 Penguin Canvas v3.1.5

本版完整保留 v3.1.4 及更早全部节点、模型、工作流、Provider 协议、默认渠道、默认值和旧画布数据，新增 GPT Image 2.5 六模型、Image G v2.5 三模型、MiniMax-H3 V2 多模态视频与 Vosr2 图像/视频超分。

## 新增与更新

- 贞贞的AI工坊图像节点 GPT2 TAB 新增 `gpt-image-2.5-flare`、`gpt-image-2.5-flare-2k`、`gpt-image-2.5-flare-4k`、`gpt-image-2.5-sunburst`、`gpt-image-2.5-sunburst-2k` 与 `gpt-image-2.5-sunburst-4k`。支持 1–10 张输出、最多 14 张有序参考图、质量/背景/审核参数、预设尺寸与受约束自定义尺寸，不改变旧 GPT Image 2 默认值和协议。
- 贞贞的平价AI小屋在现有 GPT2 TAB 的 `gpt-image-2` 下新增 `zhenzhen-image-g-v2.5-lowprice`、`zhenzhen-image-g-v2.5-flare` 与 `zhenzhen-image-g-v2.5-sunburst`。Lowprice 固定 `n=1`、最多 15 张参考图；Flare/Sunburst 支持 `n=1–4`、最多 16 张参考图，以及各自文档规定的质量、尺寸、格式、背景与审核控制。
- 贞贞的平价AI小屋视频节点 Hailuo TAB 新增大小写敏感的 `MiniMax-H3` V2。支持 480P/768P、纯文本、首尾关键帧、最多 9 张参考图、3 个参考视频、3 段参考音频、1 段驱动音频和五种音频控制；无驱动音频为 4–15 秒，提供驱动音频时为 4–60 秒。随版提供四份无凭据工作流。
- 图像节点新增 Vosr2 TAB 与 `vosr2-image-upscale`，必须且只能输入一张图片并固定输出 4K；视频节点新增 Vosr2 选项与 `vosr2-video-upscale`，必须且只能输入一个视频并固定输出 2K。两者先受控上传本地素材，完成结果立即保存本机，重启恢复只查询原任务。
- 所有新增付费生成请求均禁止不明确状态下自动重放；凭据、任务 ID、签名 URL 和 Provider 原始响应不进入公开源码、工作流或脱敏报告。

## 已核实

- GPT Image 2.5 六个模型各完成一次真实低质量文生图，另完成一次 14 张参考图编辑；七个 HTTP 200 结果均下载、解码并目检为 1024×1024 PNG。
- Image G v2.5 三个模型各完成一次真实任务且 HTTP 200：Lowprice 与 Flare 文生图、Sunburst 使用真实输出图生图；三个结果均下载、解码并完成散列校验。
- `MiniMax-H3` 完成一次真实 480P、4 秒、16:9 文生视频；结果为 864×480、约 4.458 秒的 H.264 MP4，并通过 FFprobe 与 FFmpeg 全片解码。
- Vosr2 两模型各完成一次真实任务：图片为 4096×2304 PNG；视频为 2560×1472、H.264/yuv420p、1 秒，并通过完整媒体解码。
- 专项与相邻回归、Electron ABI 重启恢复、运行权限、TypeScript、Node 语法、双语 Key、能力目录同步和 production build 已通过；正式 Windows 与 macOS 打包仍必须通过各自不可延期的发布门禁。

## 发布与证据边界

Windows 安装包、blockmap 与 `latest.yml` 必须由本机唯一一次正式发布链生成并完成远端回下载；macOS Apple Silicon DMG、ZIP 与 `latest-mac.yml` 必须由真实 `macos-15` arm64 runner 从同一不可变 `v3.1.5` Tag 构建并追加到同一非草稿、非预发布 Latest Release。未配置 Apple Developer ID 时，Mac 包继续明确为 ad-hoc 完整性签名、未公证技术预览。

反馈用户安装、多端协作、F8-F10、真人自然语言体验、设备级读屏/触控/缩放和安装升级证据按 `owner-approved-post-release-v3.1.5` 后补；延期不等于通过。测试、构建、加密、运行时、`app.asar` 启动合同、NSIS、provenance、sealed recovery、固定 Tag/target、两平台自动更新资产及远端完整性验证均不可延期。
