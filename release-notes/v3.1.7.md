# T8 Penguin Canvas v3.1.7

本版完整保留 v3.1.6 及更早全部节点、模型、工作流、Provider 协议、默认渠道、默认值和旧画布数据，集中修复后台任务已经生成成功、前端或本机代理却因短超时提前报错的问题。

## 更新内容

- 图片、视频、音频及其他生成媒体的提交、响应读取、参考素材上传、任务轮询、崩溃恢复和生成结果回下载，生产链路统一保证至少 15 分钟，不再沿用通用代理的 90 秒边界。
- 内置代理、Seedance NZ、RunningHub/FAL 工具箱、外部 Provider 适配器、ComfyUI、Jimeng CLI、导演分镜与恢复描述符均接入同一超时合同；后续新增 Provider/模型必须继续通过共享策略门。
- LLM 与媒体生成分开管理：LLM 默认 3 分钟且最长 3 分钟，避免文本请求无限占用；连接探测、重试间隔、UI 防抖和本地 FFmpeg 等非生成边界保持原有短超时。
- 付费提交的幂等、原任务查询、用户停止、失败关闭、安全下载和旧模型默认均保持不变；延长等待不会自动重发生成请求。

## 验证与证据边界

- Provider、代理、Seedance、LLM、ComfyUI、Jimeng、Photoshop、前端自定义轮询和任务恢复专项回归已覆盖新合同；版本、TypeScript、双语、能力同步、公开边界、RH 工具箱、Electron 打包和自动更新发布门由正式发布链继续校验。
- Windows 安装包、blockmap 与 `latest.yml` 只由本机唯一一次正式链生成并完整回下载校验。macOS Apple Silicon 仅在 GitHub Actions 额度可用时从同一不可变 `v3.1.7` Tag 构建 DMG、ZIP 与 `latest-mac.yml`；当前仍为 ad-hoc 完整性签名、未使用 Apple Developer ID、未公证技术预览。
- 真实用户旧库、安装升级/卸载、断电、外部设备、多端协作与 F8–F10 按 `owner-approved-post-release-v3.1.7` 后补；延期不等于通过，正式技术门、固定 Tag/target、Windows 自动更新资产与远端完整性验证不可延期。
