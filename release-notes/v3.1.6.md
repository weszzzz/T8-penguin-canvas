# T8 Penguin Canvas v3.1.6

本版完整保留 v3.1.5 及更早全部节点、模型、工作流、Provider 协议、默认渠道、默认值和旧画布数据，新增生成历史安全恢复、Creator Skill 市场首期，以及 Suno V6 工坊与平价小屋三项进阶动作。

## 新增与更新

- 生成历史改为按既有 Run/资产来源账本记录不可变生成批次，支持分页检索、节点定位、图片预览、音视频播放、历史素材找回与按内容去重，并通过权威 CanvasPatch 将结果放回当前画布。
- 图像、视频与 Seedance 2.x 的已支持输入可在明确确认后恢复提示词、基础参数和有序参考素材；缺失或内容变化的参考图必须由用户选择原文件并通过种类/散列核验，不猜测替代、不自动生成。
- Electron 关闭/退出会等待当前画布保存回执；生成失败、停止、空输出和非生成操作不会把上一版预览误记成新历史。已完成 19 个独立客户端场景 / 25 项声明、13 个 React UI 场景及最终 56/56 限定回归。
- Creator Agent 新增技能市场首期：精选/我的/搜索、SKILL.md/ZIP/文件夹导入、固定版本使用、启停与移除、完整技能文本查看/复制/继续修改。随版内置三个离线发现且宿主 Ed25519 校验的产品创作技能包；来源可信不等于效果认证。
- 贞贞的AI工坊 Suno 新增 V6、V6 Wild、V6 Mini，保留 v5.5 默认与旧画布；V6 长提示词边界和三类提交路由共享同一精确模型映射，不额外发明时长字段。
- 贞贞的平价AI小屋 Suno 目录由 31 项扩为 34 项，新增 `suno-create-model`、`suno-upload-cover` 与 `suno-upload-extend`，采用动作级字段白名单、原任务轮询与四份无凭据工作流。

## 已核实

- 生成历史当前支持范围的开发版场景、正常退出回执、素材字节/顺序/哈希、保存重启、分页竞态、停止隔离、双语 UI 与低负载限定回归均通过；未读取 retained/historical 或用户项目数据库。
- Creator Skill 市场已通过 172 项 Electron ABI、48 项前端测试、3 个技能格式校验、3 个浏览器场景、TypeScript 与双语检查；内置技能仍标记为未做效果认证。
- 工坊 Suno V6 三版本各完成一次真实提交并得到六段可完整解码 MP3；V6 和 Mini 的返回型号符合预期。Wild 请求虽使用精确 `chirp-hawk-wild`，Provider 返回仍显示 `chirp-hawk`，因此身份不冒认。
- 平价小屋 Upload Cover、Upload Extend 与 Create Model 均已有一次成功实网案例；音频、封面、模型 UUID 和保存工作流已校验，凭据、任务 ID、签名 URL 与实网产物地址不进入公开源码或工作流。

## 发布与证据边界

Windows 安装包、blockmap 与 `latest.yml` 由本机唯一一次正式发布链生成，并必须完成固定源码、加密后端、双运行时、native rebuild、app.asar/NSIS、provenance、sealed recovery、GitHub 上传和远端完整回下载。macOS Apple Silicon 仅在 GitHub Actions 额度可用时由真实 `macos-15` arm64 runner 从同一不可变 `v3.1.6` Tag 构建并追加 DMG、ZIP 与 `latest-mac.yml`；未配置 Apple Developer ID 时仍为 ad-hoc 未公证技术预览。

真实用户旧库、安装升级/卸载、断电、外部设备、多端协作、F8–F10、Creator 真实模型质量/新手试点，以及 Suno Wild 型号身份确认按 `owner-approved-post-release-v3.1.6` 后补；延期不等于通过。正式技术门、固定 Tag/target、Windows 自动更新资产与远端完整性验证不可延期。
